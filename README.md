## Key Highlights & Features

* **Full-Stack Tech Stack:** Built with **Next.js 15 (App Router)**, **React 19**, **TypeScript 5**, **Node.js**, **PostgreSQL**, **Prisma ORM**, and **Tailwind CSS 4**.
* **Full-Stack Contact API:** Server-side `/api/contact` route integrated with **Resend**, featuring **Zod** validation and secure input handling.
* **Automated QA & Testing:** Includes **Vitest** unit testing, component testing, and **Playwright** end-to-end (E2E) automation.
* **Custom Design System:** Glassmorphism UI, animated aurora backgrounds, floating code elements, and modern visual effects.
* **Interactive Developer Terminal:** Custom CLI component displaying full-stack skills, certifications, and system configurations.
* **AI-Assisted Development:** Demonstrates practical use of AI tools such as **ChatGPT, GitHub Copilot, and Claude** for rapid prototyping, documentation, test-case design, and debugging.
* **Responsive & Accessible UI:** Mobile-first, keyboard-friendly navigation with RTL/LTR localization support for English and Dari.
* **Resume Integration:** Direct, one-click access to download the professional Full-Stack CV PDF.

## Getting Started Locally

### Prerequisites

Make sure you have the following installed:

* **Node.js 18.x or later**
* **npm**
* **Git**

### 1. Clone the Repository

```bash
git clone https://github.com/Somaiyanoori/portfolio-somaiya.git
cd portfolio-somaiya
```

### 2. Install Dependencies

```bash
npm install --legacy-peer-deps
```

### 3. Create Environment File

Create a **`.env.local`** file in the root directory:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_GITHUB_USERNAME=Somaiyanoori
CONTACT_EMAIL=somayenoori786@icloud.com
RESEND_API_KEY=your_resend_api_key_here
```

> **Note:** Never commit `.env.local` or any private API keys to GitHub.

### 4. Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## Deployment

This project is optimized for deployment with **Vercel**.

### Deployment Steps

1. Push the project to GitHub.
2. Open your Vercel Dashboard.
3. Import the GitHub repository **`portfolio-somaiya`**.
4. Select **Next.js** as the framework.
5. Configure the required environment variables:

   * `RESEND_API_KEY`
   * `CONTACT_EMAIL`
6. Deploy the application.
