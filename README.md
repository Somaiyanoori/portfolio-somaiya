##  Key Highlights & Features

* ** Modern Tech Stack:** Built with **Next.js 15 (App Router)**, **React 19**, **TypeScript 5**, and **Tailwind CSS 4**.
* ** Custom Design System:** Glassmorphism UI, animated aurora backgrounds, floating code elements, and modern neon-inspired visual effects.
* ** Interactive Developer Terminal:** Custom terminal interface showcasing developer information, certifications, skills, and mission statements.
* ** AI-Enhanced Development:** Demonstrates the use of AI tools such as **ChatGPT, GitHub Copilot, and Claude** for development, debugging, documentation, and productivity.
* ** Full-Stack Contact API:** Includes a server-side `/api/contact` endpoint with **Zod** validation and secure input handling.
* ** Dynamic Scroll Spy Navbar:** Automatically highlights the active navigation section while scrolling.
* ** Automated QA & Testing:** Includes **Vitest** unit testing and **Playwright** end-to-end testing.
* ** Resume Download:** Provides direct access to the professional PDF resume.
* ** Responsive Design:** Optimized for desktop, tablet, and mobile screen sizes.
* ** Modern UI Experience:** Includes smooth animations, responsive interactions, and polished visual transitions.

## ⚡ Getting Started Locally

### Prerequisites

Make sure you have the following installed:

* **Node.js 18.x or later**
* **npm**
* **Git**

### 1. Clone the Repository

```bash
git clone https://github.com/Somaiyanoori/portfolio-somaiya.git
cd portfolio-somaiya
```

### 2. Install Dependencies

```bash
npm install --legacy-peer-deps
```

### 3. Create Environment File

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_GITHUB_USERNAME=Somaiyanoori
CONTACT_EMAIL=somayenoori786@icloud.com
```

> **Note:** Never commit `.env.local` or any private API keys to GitHub.

### 4. Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🚀 Deployment

This project is optimized for deployment with **Vercel**.

### Deployment Steps

1. Push the project to GitHub.
2. Open your Vercel Dashboard.
3. Import the GitHub repository.
4. Select **Next.js** as the framework.
5. Configure the required environment variables.
6. Use the following install command if required:

```bash
npm install --legacy-peer-deps
```

7. Deploy the application.

After deployment, your portfolio will be available through your Vercel domain.
